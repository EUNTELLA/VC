# PRD: 할일 관리 앱 (To-Do App)

## 개요

하루 10~20개 정도의 할일을 관리하는 개인용 웹 앱. 설치나 서버 없이
브라우저에서 HTML 파일을 열기만 하면 바로 사용할 수 있어야 한다.

## 대상 사용자

본인 혼자 쓰는 개인용 도구. 로그인, 다중 사용자, 기기 간 동기화는
고려하지 않는다.

## 핵심 기능

1. **할일 추가/수정/삭제**
   - 할일 텍스트와 카테고리를 입력해 추가
   - 기존 할일의 텍스트/카테고리 수정
   - 할일 삭제
2. **완료 체크**
   - 체크박스로 완료/미완료 토글
   - 완료된 항목은 시각적으로 구분(예: 취소선, 흐리게 표시)
3. **카테고리 분류**
   - 업무 / 개인 / 공부 세 가지 카테고리 중 선택
   - 카테고리별로 구분해서 보거나 필터링 가능
4. **진행률 보기**
   - 전체 할일 대비 완료한 할일의 비율을 진행률 바(%)로 표시

## 비기능 요구사항

- **실행 방식**: `index.html`을 브라우저에서 직접 열어서 사용(서버 불필요,
  빌드 과정 없음).
- **데이터 저장**: `localStorage`에 저장해 새로고침/브라우저 재시작 후에도
  데이터가 유지되어야 한다.
- **기술 스택**: 순수 HTML/CSS/JavaScript. 프레임워크, 번들러, 외부
  라이브러리 없이 구현한다.

## 데이터 모델

각 할일 항목:
```
{
  id: string,          // 생성 시점 기반 고유 ID
  text: string,        // 할일 내용
  category: "work" | "personal" | "study",
  completed: boolean,
  createdAt: number    // epoch ms
}
```

## 화면 구성

- 상단: 진행률 바(완료 개수 / 전체 개수, %)
- 할일 추가 입력창(텍스트 + 카테고리 선택) + 추가 버튼
- 카테고리 필터(전체/업무/개인/공부)
- 할일 목록: 각 항목에 체크박스, 텍스트, 카테고리 표시, 수정/삭제 버튼

## 범위 외 (Out of Scope)

- 로그인/다중 사용자
- 서버 저장 및 기기 간 동기화
- 마감일/알림/반복 할일
- 정렬·검색 등 고급 기능
